# Tech Stack

CareerCure is built with a modern, production-ready stack.

## Frontend

- **Next.js** — React framework with App Router for fast, SEO-friendly pages
- **React** — component-based UI
- **TypeScript** — type-safe development
- **Tailwind CSS** — utility-first styling

Two Next.js applications are part of the platform:

- **User portal** — student-facing application
- **Admin portal** — separate dashboard for platform administrators

## Backend

- **FastAPI** — high-performance Python API framework
- **PostgreSQL** — relational database
- **JWT** — stateless, secure authentication

## AI

- **Groq** — ultra-fast inference for LLM responses
- **Llama 3** — LLM powering the career counselor
- **LangChain** — LLM application orchestration
- **ChromaDB** — vector database for semantic search / RAG
- **HuggingFace Embeddings** — sentence embeddings for resume & job matching

## Deployment

- **Docker** — containerized deployment of the full stack
